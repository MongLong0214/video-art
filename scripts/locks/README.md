# Closed-lock plate rebuilders

Custom flow/hold plates for locked products. **Not optional** when `recipes/locks/manifest.json` has a `plates` field.

```bash
npx tsx scripts/rebuild-closed-lock.ts --slug r325-ganesha-rainbow-rings-master
npx tsx scripts/rebuild-closed-lock.ts --slug r342-cosmic-buddha-eye-fall
```

See `docs/video-os/04-QUALITY-CONTRACT.md` §3 and `docs/video-os/02-REPRO-LOCKS.md` §3.
